# I2CSniffer-Injector

A learning project to understand I²C communication and eventually
build an I²C protocol sniffer and injector using Raspberry Pi Pico 2.

## Goals

- Learn how I²C works at the electrical and protocol level
- Build a passive I²C sniffer
- Decode START and STOP conditions
- Decode addresses
- Decode READ and WRITE operations
- Decode ACK and NACK
- Build an I²C injector
- Test the sniffer and injector against each other
- Experiment with an MCP9808 temperature sensor
- Experiment with an I²C OLED display
- Learn about Pico 2 GPIO, PIO, DMA, and USB

## Planned Hardware

- Raspberry Pi Pico 2 × 2
- Adafruit MCP9808 temperature sensor breakout
- Adafruit 0.96" I²C OLED display
